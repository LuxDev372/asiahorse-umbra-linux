AsiaHorse Umbra – Linux desktop GUI

Keep all files in this folder together.
Install Python Tk and the USB permission rule using the distribution-specific
instructions in README.md. If Tk is already installed, no reinstall is needed.

From this folder, run:
python3 asiahorse_gui.py

Choose an effect and press Start / apply.
Press the same button to apply changes to color, speed or brightness.
Stop freezes the last frame; Turn off RGB switches the LEDs off.
Closing the app leaves the last frame lit. Animations require the app to stay open.

All five effects have been reported working on an Umbra hub with Bazzite.
Use one running app instance and do not run other RGB controllers simultaneously.
For full installation steps, limitations and credits, see README.md.
